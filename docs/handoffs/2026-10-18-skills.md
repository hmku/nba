## Problems encountered (CLI findings - see "Notes for next agent")
1. `fantasy run end` does not release the run's locks; an ended run keeps blocking others until TTL.
2. `fantasy draft init --draft-id mock-x` without `--mock` creates a non-mock draft that becomes the
   default for every `draft` command ("latest non-mock draft") - dangerous on draft night.
3. `draft prepare-pick` cannot retry after a failed draft_pick txn for the same player/pick (exit 5
   duplicate, no `--attempt`). Workaround: `txn plan draft_pick --payload {...} --attempt 2` ->
   `txn mark submitted` -> click -> `draft confirm-pick` (decision must be logged manually).
4. Reconciling a draft pick with `txn mark verified` does not record the pick on the board, and
   `confirm-pick` then exits 7. Use `confirm-pick` for draft picks.
5. A `dry_run` `prepare-pick` leaves a `planned` txn that a later live run silently reuses (txn.run_id
   stays the dry run's). Also each prepare-pick call logs another decision.
6. `prepare-pick` gives no warning when the board has gaps (`recommend` does).
7. `draft simulate` ignores the custom order from `set-order` (uses the formula order).
8. `recommend` always uses default valuation params; `values build --kappa/--punt` don't affect it.
9. Validation gaps: `values build --punt bogus` silently accepted; `recommend --strategy bogus` ->
   KeyError traceback (exit 1); `recommend --objective bogus` accepted; `set-order` with wrong round
   count exits 1 (not 2).
10. `approval show --wait N` exits 0 while still pending (callers must read `approval.status`).
11. JSON without `"ok"`: `data build-projections`, `data top` (a list), `values build`, `draft board`,
    `draft queue`, `draft order`, `simulate` - the runbook says every command has `ok`.
12. `data/manual/league_settings.json` does not exist yet (CLAUDE.md implies it does);
    `settings verify` creates it.
13. Overrides for Jimmy Butler, Mark Williams, Donte DiVincenzo, Jordan Miller produce no output row
    (cut by the 450-row relevance limit) - silently.
14. Task T-009 "Monte Carlo draft simulation" is still `todo` although `fantasy draft simulate` exists.
15. `recommend --objective matchup` gave a very different top-3 from `cat_wins` on a test board.
