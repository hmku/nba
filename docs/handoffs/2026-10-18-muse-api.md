# Handoff 2026-10-18 — external-agent API for Meta Muse

## What changed (web/ + docs; backend untouched)
- **Token-protected API** `/api/agent/*` on the dashboard for the user's outside assistant **Meta Muse** (can read the
  league's Messenger group chat). Auth `Authorization: Bearer $AGENT_API_TOKEN` (server-only env; sha256 +
  timingSafeEqual; unset → 503 `AGENT_API_TOKEN not configured`; wrong → 401). All responses JSON with `ok`.
  - `GET /api/agent` (public endpoint list), `GET state` (active non-mock draft: clock, my picks incl. custom order,
    last 12, gaps; latest rec top 5 + stale; my roster; season outlook; pending approvals; last 10 events),
    `GET players?q=` (search, drafted?), `POST pick` (observed pick, `source='external_agent'`, never overwrites:
    409 on conflict, 422 + candidates for ambiguous names), `POST report` (league intel → `agent_events`
    `observation` under the day's run `muse-YYYY-MM-DD`, agent `muse`, dry_run; ≤ 60 muse events/hour → 429).
  - Nothing in this API touches Yahoo. Details: `docs/runbooks/dashboard.md` → "External-agent API".
- **`/agent`** public instructions page = `web/src/content/muse.md`, copied verbatim to `docs/integrations/muse.md`
  (unit test enforces identical; edit the web copy then `cp`). Includes a ready-to-paste prompt for Muse.
- **Activity**: "League intel from Muse" list (report-kind badge + source badge, details JSON) and badges on those
  events in the run timeline; the muse run is excluded from the "stuck running" warning.
- **Tests**: `npm test` (node --test on `web/tests/agent.test.mjs`, Node ≥ 22.18 type stripping) covers token check,
  name resolution (accents, Jr., "V. Wembanyama", fuzzy, ambiguity), search, board clock/gaps, rec freshness, 3RR
  picks, report/pick validation, muse run id (ET day), doc copy identical. Added to CI (`.github/workflows/ci.yml`).
