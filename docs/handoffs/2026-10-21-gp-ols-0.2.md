# Handoff 2026-10-21 - games-played model gp-ols-0.2 (side session of the main local session, local)

## What was accomplished
- Refit the availability model `gp-ols-0.1 -> gp-ols-0.2` (`src/fantasy/model/availability.py`), fixing the two issues of the
  2026-10-21 subgroup check (top-end optimism; extrapolation for < 500-minute players). Details, tables and caveats:
  `docs/research/availability_model.md` §0.
  - Main model: + role hinge `max(0, 30 - mpg1)`; young bonus only when g1 < 70.
  - Recent-era calibration `raw - 1.44 - 0.16*max(0, raw - 65)` from rolling-origin forecast errors 2019-2024.
  - New low-minute / lost-season model (prior minutes, g1, mpg1, lost, age), blended with the main model over 400-600 min.
  - gp_sd knots refit; manual gp now gets the sd of its own level; guard against an incomplete latest season.
- Fit pipeline is now committed: `scripts/gp_model/` (`panel.py`, `fit_gp.py`, README, `report_gp-ols-0.2.json`).
- Versions: `gp-ols-0.2`, projections `baseline-0.2.2`, `projections-2026-27-0.3.1`. Rebuilt projections, values
  (`val-20261021233531-fecc33`) and the season sim (`sim-20261021233550-a97895`, 12k sims, seed 0) on production Postgres.
- Evidence (fitted, strict OOS = fit on targets <= 2024): RMSE vs 0.1 2025 19.06 -> 18.58 (0.48 +- 0.21), 2026 20.05 -> 19.93
  (0.13 +- 0.19). The spec was chosen on 2019-26 rolling residuals, so the honest gain is about 0.1-0.3. For low-minute players
  RMSE improves 2.5 / 3.0 +- 1.2 and the bias goes from -9.5 to about +3, which censoring flatters.
- Effect (simulated): my P(playoffs) 91.2% -> 89.0%, P(title) 32.3% -> 30.6%, exp. rank 2.7 -> 2.9. Our games edge narrows
  (46.7 -> 46.5 player-games/week, while most rivals gain ~0.5). Category ranks: ast 2->4, ft% 5->4, tov 7->6.

## Decisions & rationale
- mpg hinge rather than a total-minutes hinge: same RMSE, but total minutes drove the g1 coefficient to 0.04, which would
  ignore injury-shortened seasons of starters.
- Calibration excludes 2025-26 because their 0-game seasons are not observable yet (censoring). With them, h would be -0.30,
  and per-year h has been strongly negative since 2022, so the top-end shrink may be too weak. Recalibrate after 2026-27.
- quant-reviewer verdict: "ship with changes". All of its model issues were fixed: low-model under-prediction of injured
  starters and lost seasons, censoring, h shrink, honest gain wording, the 500-minute jump, the manual-gp sd, the guard and the tests.
- ESPN games are not blended in (they run ~12 games optimistic).
